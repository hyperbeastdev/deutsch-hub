# Design-system rule

- Use semantic tokens for color, typography, spacing, radius, elevation and motion.
- Establish a clear type hierarchy and predictable spacing before adding decoration.
- Design mobile and desktop layouts deliberately, with no accidental overflow or giant empty regions.
- Support light/dark themes, visible focus, keyboard input, reduced motion and accessible names.
- Prefer calm surfaces and purposeful color over gradients, glass, excessive cards, pills, emojis or ornamental animation.
- Reuse primitives for repeated interaction patterns; do not create one-off visual systems inside feature components.
- Validate important states visually in a browser when browser control is available.
